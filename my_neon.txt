# 本文档基于对 LVGL, minimp3, Opus, FLAC, FFTW 等多个开源项目的
# NEON 代码进行静态分析后汇总而成，代表了这些领域真实在用的指令集。

# ------------------------------------------------------------------------------
# 0. 基础概念与术语 (Basic Concepts & Terminology)
# ------------------------------------------------------------------------------
#
# 寄存器 (Registers):
# NEON 寄存器组由 V0-V31 组成 (AArch64)。
# - 128位宽 (Quadword): Q0-Q31。在C intrinsic中通常对应带 'q' 后缀的类型(如 int8x16_t)。
# - 64位宽 (Doubleword): D0-D31。对应 V 寄存器的低64位。在C intrinsic中对应不带 'q' 的类型(如 int8x8_t)。
#
# 数据类型 (Types) - arm_neon.h:
# 命名规则: baseWxL_t
# - base: 基础类型 (int, uint, float)
# - W: 宽度 (8, 16, 32, 64)
# - L: 向量中的元素数量 (Lane count)
# 示例:
# - int8x8_t:  8个8位有符号整数，总宽64位 (使用 D 寄存器)。
# - int8x16_t: 16个8位有符号整数，总宽128位 (使用 Q 寄存器)。
#
# 关键后缀说明 (Suffixes):
# - q (Quad): 表示操作 128 位向量 (例如 vaddq_s32)。若无 q 通常指 64 位。
# - l (Long): 变长指令。输入通常是64位，结果扩展为128位；或输入是窄类型，输出是宽类型 (如 vmull_s16)。
# - n (Narrow): 变窄指令。输入是宽类型，输出是窄类型 (如 vmovn_s32)。
# - _high: (AArch64) 操作涉及128位寄存器的高64位部分。
#    - 变宽时: 取源寄存器的高64位进行运算。
#    - 变窄时: 结果写入目标寄存器的高64位。
# - _lane: 操作数取自向量的特定通道。
# - _n: 操作数是标量。
#
# ------------------------------------------------------------------------------

# ------------------------------------------------------------------------------
# 1. 算术运算 (Arithmetic Operations)
# ------------------------------------------------------------------------------
# 向量加减法 (64位可能用的不多，但有最好)

v<add/sub>[q]_<s/u><8/16/32/64>
ADD/SUB 整数加减
# ------------------------------------------------------------------------------
# 说明: 标准整数加法/减法。
# 操作: 对应位置的元素相加/相减，结果不饱和，溢出部分直接截断(Wrap around)。
# 寄存器视图 (以vadd.i16 d0, d1, d2为例):
#   d0[15:0]  = d1[15:0]  + d2[15:0]
#   d0[31:16] = d1[31:16] + d2[31:16]
#   ...
# 位宽: 支持 8/16/32/64 位整数。
#   - Q后缀(128位): 16x8, 8x16, 4x32, 2x64
#   - 无Q后缀(64位): 8x8, 4x16, 2x32, 1x64
# 标志位: 不影响 FPSCR 标志位。
# ------------------------------------------------------------------------------

v<add/sub>[q]_f<32/64>
FADD/FSUB 浮点加减
# ------------------------------------------------------------------------------
# 说明: IEEE 754 标准浮点加法/减法。
# 操作: 对应位置的浮点数相加/相减。需处理 NaN, Infinity, Denormal 等情况。
# 寄存器视图 (以vadd.f32 q0, q1, q2为例):
#   q0[31:0]   = q1[31:0]   + q2[31:0]
#   q0[63:32]  = q1[63:32]  + q2[63:32]
#   q0[95:64]  = q1[95:64]  + q2[95:64]
#   q0[127:96] = q1[127:96] + q2[127:96]
# 位宽: 支持 32位(单精度) 和 64位(双精度) 浮点。
# ------------------------------------------------------------------------------

vq<add/sub>[q]_<s/u><8/16/32/64>
vq<add/sub><b/h/s/d>_<s/u><8/16/32/64> # 标量饱和加减
SQADD 有符号饱和加法
UQADD 无符号饱和加法
SQSUB 有符号饱和减法
UQSUB 无符号饱和减法
# ------------------------------------------------------------------------------
# 说明: 饱和整数加法/减法 (Saturating Add/Sub)。
# 操作: 对应位置元素相加/减。如果结果超出该数据类型能表示的范围，则钳位到最大值或最小值。
#   - 有符号饱和(SQ): 上溢钳位到 MAX_INT (例如8位是127)，下溢钳位到 MIN_INT (-128)。
#   - 无符号饱和(UQ): 上溢钳位到 MAX_UINT (例如8位是255)，下溢钳位到 0。
# 寄存器视图 (以vqadd.s8 d0, d1, d2为例):
#   d0[7:0] = clamp(d1[7:0] + d2[7:0], -128, 127)
# 位宽: 8/16/32/64 位。
# 特殊: 标量版本只操作向量寄存器的最低元素 (lane 0)，高位保持不变或置零(视架构具体实现而定，通常NEON标量指令只更新目标lane)。
# ------------------------------------------------------------------------------

# 向量乘法
vmul[q]_<s/u><8/16/32>
MUL 整数乘法
# ------------------------------------------------------------------------------
# 说明: 标准整数乘法，结果不扩展。
# 操作: 对应位置元素相乘，结果截断为原位宽。相当于 (a * b) & mask。
# 寄存器视图 (以 vmul.i16 d0, d1, d2 为例):
#   d0[15:0] = (d1[15:0] * d2[15:0]) 的低16位
# 位宽: 8/16/32 位。
# 注意: 8x8的结果如果超过8位会被截断。如果需要完整结果请用 vmull。
# ------------------------------------------------------------------------------

vmul[q]_f<32/64>
FMUL 浮点乘法
# ------------------------------------------------------------------------------
# 说明: 向量浮点乘法。
# 操作: 对应位置的浮点元素相乘。
# 寄存器视图 (以 vmul.f32 q0, q1, q2 为例):
#   q0[31:0]   = q1[31:0]   * q2[31:0]
#   q0[63:32]  = q1[63:32]  * q2[63:32]
#   q0[95:64]  = q1[95:64]  * q2[95:64]
#   q0[127:96] = q1[127:96] * q2[127:96]
# 位宽: 32/64 位浮点。
# ------------------------------------------------------------------------------

vmull[q]_<s/u><8/16/32>
SMULL 有符号乘法并扩展
UMULL 无符号乘法并扩展
# ------------------------------------------------------------------------------
# 说明: 变长乘法 (Long Multiply)。输入变窄，输出变宽。
# 操作: 两个 N 位数相乘，得到 2N 位结果。
# 输入/输出:
#   - 输入: 8位 -> 输出: 16位
#   - 输入: 16位 -> 输出: 32位
#   - 输入: 32位 -> 输出: 64位
# 寄存器视图 (以 vmull.s16 q0, d1, d2 为例):
#   q0[31:0]  = (int32_t)d1[15:0]  * (int32_t)d2[15:0]
#   q0[63:32] = (int32_t)d1[31:16] * (int32_t)d2[31:16]
#   ...
#   (输入用D寄存器，输出用Q寄存器)
# ------------------------------------------------------------------------------

# 向量饱和加倍乘法
vq[r]dmul[h/l][q][_lane]_<s/u><8/16/32/64>
# ------------------------------------------------------------------------------
# 说明: 定点DSP运算核心指令 - 饱和加倍乘法。
# 常用指令: vqdmulh (High Half), vqrdmulh (Rounding High Half)
# 操作 (vqdmulh.s16):
#   result = SATURATE((a * b * 2) >> 16)
#   即: 两个Q15定点数相乘，结果仍为Q15。
#   *2 的原因是 Q15*Q15 = Q30，为了变回Q15 (range -1 to ~1)，需要左移1位(x2)变成Q31，然后取高16位。
# 后缀:
#   - h: High, 取高半部分 (相当于除以 2^N)。
#   - r: Rounding, 也就是 (a*b*2 + round_const) >> N。
# ------------------------------------------------------------------------------

# ------------------------------------------------------------------------------

# 向量比特与
vand[q]_<s/u><8/16/32/64>
AND
# ------------------------------------------------------------------------------
# 说明: 按位与 (Bitwise AND)。
# 操作: 对整个寄存器进行按位与操作，不区分元素边界。
# 寄存器视图 (以 vand q0, q1, q2 为例):
#   q0[127:0] = q1[127:0] & q2[127:0]
# ------------------------------------------------------------------------------

# 向量比特或
vorr[q]_<s/u><8/16/32/64>
ORR
# ------------------------------------------------------------------------------
# 说明: 按位或 (Bitwise OR)。
# 操作: 对整个寄存器进行按位或操作。
# 寄存器视图 (以 vorr q0, q1, q2 为例):
#   q0[127:0] = q1[127:0] | q2[127:0]
# ------------------------------------------------------------------------------

# 向量比特非
vmvn[q]_<s/u><8/16/32/64>
MVN
# ------------------------------------------------------------------------------
# 说明: 按位非 (Bitwise NOT / Move Not)。
# 操作: 对源寄存器按位取反后写入目标寄存器。
# 寄存器视图 (以 vmvn q0, q1 为例):
#   q0[127:0] = ~q1[127:0]
# ------------------------------------------------------------------------------

# 向量比特异或
veor[q]_<s/u><8/16/32/64>
EOR
# ------------------------------------------------------------------------------
# 说明: 按位异或 (Bitwise XOR)。
# 操作: 对整个寄存器进行按位异或操作。
# 寄存器视图 (以 veor q0, q1, q2 为例):
#   q0[127:0] = q1[127:0] ^ q2[127:0]
# ------------------------------------------------------------------------------

# 向量比特选择
vbsl[q]_<s/u/f><8/16/32/64>
BSL
# ------------------------------------------------------------------------------
# 说明: 按位选择 (Bitwise Select)。
# 操作: 根据掩码(mask)的每一位选择结果来源。如果掩码位为1，选第一个操作数(src1)；为0，选第二个操作数(src2)。
# 寄存器视图 (以 vbsl q0, q1, q2 为例，q0是mask也是dest):
#   注意: 在汇编中 BSL 目标寄存器也是第一个源操作数 (Dest = Mask)。
#   q0[i] = (q0[i] == 1) ? q1[i] : q2[i]  (对于每一位 i)
#   即: q0 = (q0 & q1) | (~q0 & q2)
# ------------------------------------------------------------------------------

# ------------------------------------------------------------------------------
# 5. 移位运算 (Shift Operations)
# ------------------------------------------------------------------------------

# 左移
vshl[q]_n_<s/u><8/16/32/64>
SHL     左移立即数
# ------------------------------------------------------------------------------
# 说明: 左移立即数 (Shift Left by Immediate)。
# 操作: 将向量的每个元素向左移动固定位数(立即数)。空出的低位补0。
# 寄存器视图 (以 vshl.i16 q0, q1, #2 为例):
#   q0[15:0]  = q1[15:0]  << 2
#   q0[31:16] = q1[31:16] << 2
#   ...
# ------------------------------------------------------------------------------

vshl[q]_s<8/16/32/64>
SSHL    有符号左移寄存器，为负则是右移
vshl[q]_u<8/16/32/64>
USHL    无符号左移寄存器，为负则是右移
# ------------------------------------------------------------------------------
# 说明: 变量移位 (Shift Left by Register)。
# 特性: 移位量由寄存器提供，支持每个lane有不同的移位量。
# 关键点: 支持负数移位量! 如果移位量为负，则实际上是向右移位。
#   - SSHL (Signed Shift Left): 负数移位量导致算术右移 (保留符号位)。
#   - USHL (Unsigned Shift Left): 负数移位量导致逻辑右移 (高位补0)。
# 寄存器视图 (以 vshl.s16 q0, q1, q2 为例):
#   if (q2[15:0] >= 0) q0[15:0] = q1[15:0] << q2[15:0];
#   else               q0[15:0] = q1[15:0] >> (-q2[15:0]);
# ------------------------------------------------------------------------------

vshll_n_s<8/16/32/64>
SSHLL   有符号左移寄存器，并扩展
vshll_n_u<8/16/32/64>
USHLL   无符号左移寄存器，并扩展
# ------------------------------------------------------------------------------
# 说明: 变长左移立即数 (Shift Left Long)。
# 操作: 移位的同时，将数据位宽加倍(扩展)。通常用于将窄位宽数据提升为宽位宽(如8位转16位)。
# 寄存器视图 (以 vshll.s8 q0, d1, #0 为例):
#   q0[15:0]  = (int16_t)d1[7:0]   << 0
#   q0[31:16] = (int16_t)d1[15:8]  << 0
#   ...
#   (常用于纯粹的符号扩展或零扩展，只要移位量为0即可)
# ------------------------------------------------------------------------------

vqshl[q/l][_n]_s<8/16/32/64>
SQSHL
vqshl[q/l][_n]_u<8/16/32/64>
UQSHL
# ------------------------------------------------------------------------------
# 说明: 饱和左移 (Saturating Shift Left)。
# 操作: 左移，如果结果溢出该数据类型的范围，则进行饱和处理(Clamp)。
# 寄存器视图 (以 vqshl.s16 q0, q1, #2 为例):
#   q0[i] = SATURATE(q1[i] << 2)
#   如果 q1[i] << 2 > 32767, 则 q0[i] = 32767
#   如果 q1[i] << 2 < -32768, 则 q0[i] = -32768
# ------------------------------------------------------------------------------

# 右移
vshr[q]_n_s<8/16/32/64>
SSHR    有符号右移立即数
vshr[q]_n_u<8/16/32/64>
USHR    无符号右移立即数
# ------------------------------------------------------------------------------
# 说明: 右移立即数 (Shift Right by Immediate)。
# 变体:
#   - SSHR (Signed): 算术右移，符号位填充。
#   - USHR (Unsigned): 逻辑右移，高位补0。
# 寄存器视图 (以 vshr.s16 q0, q1, #2 为例):
#   q0[15:0] = q1[15:0] >> 2  (保留符号位)
# ------------------------------------------------------------------------------

vshrn_n_<s/u><8/16/32/64>
SHRN    右移立即数，缩小，取低半
SHRN2   右移立即数，缩小，取高半
# ------------------------------------------------------------------------------
# 说明: 变窄右移 (Shift Right Narrow)。
# 汇编指令:
#   - SHRN (Shift Right Narrow): 读取源寄存器(128位)，右移并截断，结果写入目标寄存器(64位)。
#   - SHRN2 (Shift Right Narrow High): (AArch64) 读取源寄存器(128位)，右移并截断，结果写入目标寄存器的高64位(保持低64位不变)。
# 寄存器视图 (以 vshrn_n_s16 d0, q1, #8 为例 -> SHRN d0, q1, #8):
#   d0[7:0]  = (int8_t)(q1[15:0]  >> 8)
#   d0[15:8] = (int8_t)(q1[31:16] >> 8)
#   ...
#   (常用于数据打包，如 16-bit PCM -> 8-bit Audio)
#
# 寄存器视图 (以 vshrn_high_n_s16 q0, q2, #8 为例 -> SHRN2 v0.16b, v2.8h, #8):
#   注意: 输入是 q2(128位)，输出是 q0 的高64位 (q0[127:64])。
#   q0[71:64]   = (int8_t)(q2[15:0]  >> 8)
#   q0[79:72]   = (int8_t)(q2[31:16] >> 8)
#   ...
#   q0[127:120] = (int8_t)(q2[127:112] >> 8)
#   (q0的低64位保持不变)
# ------------------------------------------------------------------------------

# rounding左右移
vrshl[q]_s<8/16/32/64>
SRSHL
vrshl[q]_u<8/16/32/64>
URSHL
vrshr[q]_n_s<8/16/32/64>
SRSHR
vrshr[q]_n_u<8/16/32/64>
URSHR
# ------------------------------------------------------------------------------
# 说明: 带圆整的移位 (Rounding Shift)。
# 区别: 普通移位是向下取整 (Floor)，Rounding 移位是四舍五入 (Round to nearest)。
# 操作: 相当于 (x + (1 << (shift-1))) >> shift。
# 场景: 信号处理中为了减少多次移位造成的直流偏差(DC Bias)。
# ------------------------------------------------------------------------------

vqrshl[q]_s<8/16/32/64>
SQRSHL
vqrshl[q]_u<8/16/32/64>
UQRSHL
# ------------------------------------------------------------------------------
# 说明: 饱和带圆整左移 (Saturating Rounding Shift Left)。
# 操作: 先做圆整左移，然后对结果进行饱和处理。
# ------------------------------------------------------------------------------

vsra[q]_n_s<8/16/32/64>
SSRA
vsra[q]_n_u<8/16/32/64>
USRA
vrsra[q]_n_s<8/16/32/64>
SRSRA
vrsra[q]_n_u<8/16/32/64>
URSRA
# ------------------------------------------------------------------------------
# 说明: 右移并累加 (Shift Right and Accumulate)。
# 操作:
#   SSRA/USRA: Acc += (Val >> Shift)
#   SRSRA/URSRA: Acc += Round(Val >> Shift)
# 寄存器视图 (以 vsra.s16 q0, q1, #2 为例):
#   q0[15:0] += q1[15:0] >> 2
# ------------------------------------------------------------------------------

# 加载数据 (Load)
# NEON 加载指令非常强大，不仅支持连续加载，还支持结构化加载(Structure Load)，
# 即在加载时自动进行数据解交织(De-interleave)。

vld1[q][_lane]_<s/u/f><8/16/32/64>[_x2/3/4]
LD1
# ------------------------------------------------------------------------------
# 说明: 加载单一连续块 (Load Single Structure)。
# 操作: 从内存加载连续的数据到寄存器。
# 寄存器视图 (以 vld1.8 {d0}, [ptr] 为例, ptr指向内存 [A, B, C, D, E, F, G, H]):
#   d0[7:0]   = A
#   d0[15:8]  = B
#   ...
#   d0[63:56] = H
# ------------------------------------------------------------------------------

vld2[q][_lane]_<s/u/f><8/16/32/64>
LD2
# ------------------------------------------------------------------------------
# 说明: 加载2元素结构 (Load 2-element Structure)。
# 场景: 典型如立体声(Stereo)音频数据 (L, R, L, R...)。
# 操作: 加载时自动将L和R分开到两个寄存器。
# 寄存器视图 (以 vld2.16 {d0, d1}, [ptr] 为例):
#   内存: [L0, R0, L1, R1, L2, R2, L3, R3] (每个元素16位)
#   d0: [L0, L1, L2, L3] (左声道)
#   d1: [R0, R1, R2, R3] (右声道)
# ------------------------------------------------------------------------------

vld3[q][_lane]_<s/u/f><8/16/32/64>
LD3
# ------------------------------------------------------------------------------
# 说明: 加载3元素结构 (Load 3-element Structure)。
# 场景: RGB图像数据 (R, G, B, R, G, B...)。
# 操作: 加载时自动解交织到三个寄存器。
# 寄存器视图 (以 vld3.8 {d0, d1, d2}, [ptr] 为例):
#   内存: [R0, G0, B0, R1, G1, B1, ... R7, G7, B7]
#   d0: [R0, R1, ... R7] (Red分量)
#   d1: [G0, G1, ... G7] (Green分量)
#   d2: [B0, B1, ... B7] (Blue分量)
# ------------------------------------------------------------------------------

vld4[q][_lane]_<s/u/f><8/16/32/64>
LD4
# ------------------------------------------------------------------------------
# 说明: 加载4元素结构 (Load 4-element Structure)。
# 场景: RGBA图像数据 (R, G, B, A, ...)。
# 操作: 加载时自动解交织到四个寄存器。
# 寄存器视图 (以 vld4.8 {d0, d1, d2, d3}, [ptr] 为例):
#   内存: [R0, G0, B0, A0, ... R7, G7, B7, A7]
#   d0: [R0, R1, ... R7]
#   d1: [G0, G1, ... G7]
#   d2: [B0, B1, ... B7]
#   d3: [A0, A1, ... A7]
# ------------------------------------------------------------------------------

vld1[q]_dup_<s/u/f><8/16/32/64>
LD1R
vld2[q]_dup_<s/u/f><8/16/32/64>
LD2R
vld3[q]_dup_<s/u/f><8/16/32/64>
LD3R
vld4[q]_dup_<s/u/f><8/16/32/64>
LD4R
# ------------------------------------------------------------------------------
# 说明: 加载并复制 (Load and Replicate / Broadcast)。
# 操作: 从内存加载一个元素(或一个结构单元)，并复制填充到整个向量。
# 寄存器视图 (以 vld1_dup_s32 {q0}, [ptr] 为例, 内存 [A]):
#   q0: [A, A, A, A]
# 寄存器视图 (以 vld2_dup_s16 {d0, d1}, [ptr] 为例, 内存 [L, R]):
#   d0: [L, L, L, L]
#   d1: [R, R, R, R]
# ------------------------------------------------------------------------------

# 加载到特定通道 (Load Single Element to Lane)
# (虽然vld指令列表中包含_lane后缀，但这里单独列出以便区分)
# ------------------------------------------------------------------------------
# 说明: 加载单个元素到向量的特定通道 (Load to Lane)。
# 操作: 只修改向量中的一个元素，其他元素保持不变(AArch64)或未定义(ARMv7取决于实现，通常保持不变)。
# 寄存器视图 (以 vld1_lane_s16 {d0}, [ptr], 2 为例, 内存 [X]):
#   假设 d0 原值为 [A, B, C, D]
#   执行后 d0: [A, B, X, D] (index 2 被修改)
# 结构化加载到通道 (vld2/3/4_lane):
#   操作: 从内存加载一个结构单元，分别放入多个寄存器的同一个通道索引中。
#   寄存器视图 (以 vld2_lane_s16 {d0, d1}, [ptr], 1 为例, 内存 [L, R]):
#     d0: [A, L, C, D] (index 1 被 L 覆盖)
#     d1: [E, R, G, H] (index 1 被 R 覆盖)
# ------------------------------------------------------------------------------

# 合并提取
vext[q]_<s/u/f><8/16/32/64>

# ------------------------------------------------------------------------------
# 说明: 提取 (Extract)。
# 操作: 从两个连接的向量中提取一个新的向量。相当于滑动窗口。
# 寄存器视图 (以 vext.8 d0, d1, d2, #3 为例):
#   连接 d1, d2: [d1[0]...d1[7], d2[0]...d2[7]]
#   提取从 index 3 开始的 8 个字节:
#   d0 = [d1[3], d1[4], d1[5], d1[6], d1[7], d2[0], d2[1], d2[2]]
# ------------------------------------------------------------------------------

SMOV
UMOV
# ------------------------------------------------------------------------------
# 说明: 获取元素/部分。
#   - vget_high: 获取Q寄存器的高64位 (返回D寄存器)。
#   - vget_low:  获取Q寄存器的低64位 (返回D寄存器)。
#   - vget_lane: 获取特定通道的标量值。
# 寄存器视图 (以 vget_lane_s16 r0, d0, 2 为例):
#   r0 = d0[2] (即获取第3个16位元素)

# 顺序反转
vrev<16/32/64>[q]_<s/u/f><8/16/32>
REV64
REV32
REV16
# ------------------------------------------------------------------------------
# 说明: 元素反转 (Reverse Elements)。
# 变体:
#   - REV64: 在64位块内反转元素顺序。
#   - REV32: 在32位块内反转元素顺序。
#   - REV16: 在16位块内反转元素顺序。
# 寄存器视图 (以 vrev32.8 d0, d1 为例, 8位元素, 在32位块内反转):
#   d1: [A, B, C, D,  E, F, G, H]  (d1[0]=A ... d1[7]=H)
#   32位块1: [A, B, C, D] -> 反转 -> [D, C, B, A]
#   32位块2: [E, F, G, H] -> 反转 -> [H, G, F, E]
#   d0: [D, C, B, A,  H, G, F, E]
# ------------------------------------------------------------------------------

# 转置
vtrn[1/2][q]_<s/u/f><8/16/32/64>
TRN1
TRN2
# ------------------------------------------------------------------------------
# 说明: 转置 (Transpose)。
# 操作: 从两个向量中交替选取偶数索引或奇数索引的元素进行重组。
# 寄存器视图 (以 vtrn.8 d0, d1 为例, 8位元素):
#   输入:
#     d0: [A0, A1, A2, A3, A4, A5, A6, A7]
#     d1: [B0, B1, B2, B3, B4, B5, B6, B7]
#   输出 (TRN1 d0, d1 - 选取偶数位置元素):
#     d0: [A0, B0, A2, B2, A4, B4, A6, B6]
#   输出 (TRN2 d0, d1 - 选取奇数位置元素):
#     d1: [A1, B1, A3, B3, A5, B5, A7, B7]
# ------------------------------------------------------------------------------

# 交织
vzip[1/2][q]_<s/u/f><8/16/32/64>
ZIP1
ZIP2
# ------------------------------------------------------------------------------
# 说明: 交织 (Zip / Interleave)。
# 操作: 将两个向量的 低半部 或 高半部 像拉链一样交错合并。
# 寄存器视图 (以 vzip.8 d0, d1 为例, 8位元素):
#   输入:
#     d0: [A0, A1, A2, A3, A4, A5, A6, A7]
#     d1: [B0, B1, B2, B3, B4, B5, B6, B7]
#   输出 (ZIP1 d0, d1 - 交织低半部分 [0-3]):
#     d0: [A0, B0, A1, B1, A2, B2, A3, B3]
#   输出 (ZIP2 d0, d1 - 交织高半部分 [4-7]):
#     d1: [A4, B4, A5, B5, A6, B6, A7, B7]
# ------------------------------------------------------------------------------

# 查表
v[q]tbl<1/2/3/4>_<s/u>8
TBL
# ------------------------------------------------------------------------------
# 说明: 查表 (Table Lookup)。
# 操作: 使用索引向量在查找表(由1-4个寄存器组成)中查找数据。
# 原理: 查找表被视为一个连续的字节数组(Table[0..N-1])。
#   - Table 由 1~4 个 64位(D) 寄存器组成 (AArch32 VTBL)。
#   - Table 由 1~4 个 128位(V) 寄存器组成 (AArch64 TBL)。
# 寄存器视图 (以 vtbl1.8 d0, {d1}, d2 为例 - 表是d1, 索引是d2):
#   Table = d1 (8 bytes, indices 0-7)
#   Indices = d2 (8 bytes)
#   对于 d0 的每个字节 i:
#     idx = d2[i]
#     if idx < 8: d0[i] = Table[idx]
#     else:       d0[i] = 0
# 寄存器视图 (以 AArch64 tbl v0.16b, {v1.16b, v2.16b}, v3.16b 为例):
#   Table = {v1, v2} (32 bytes, indices 0-31)
#   Indices = v3 (16 bytes)
#   对于 v0 的每个字节 i:
#     idx = v3[i]
#     if idx < 32: v0[i] = Table[idx]
#     else:        v0[i] = 0
# ------------------------------------------------------------------------------
